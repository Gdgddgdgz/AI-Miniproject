# AutoML Studio frontend

React 19 and Vite frontend for the AutoML Studio API.

## Run locally

```powershell
npm install
npm run dev
```

By default, the frontend calls `http://localhost:8000`. Set `VITE_API_URL` in a local `.env` file when the API runs elsewhere.

## Available commands

- `npm run dev` starts the development server.
- `npm run build` creates the production bundle.
- `npm run preview` serves the production bundle locally.
- `npm run lint` runs ESLint.

See the repository README for backend setup, dataset formats, and the overall workflow.
